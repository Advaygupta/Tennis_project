# Data files

Raw and generated datasets are intentionally not committed.

The workflow downloads annual ATP, Challenger/qualifying and Futures CSVs from Jeff Sackmann's `tennis_atp` repository, then produces a large feature table and six V1.1 model matrices. Consult the first two notebooks for the transformations and `reproducibility_notes.md` for generated filenames.

Before redistributing raw or row-level derived data, confirm the applicable upstream terms. For private reproduction, retain source-file hashes, the upstream commit where available, and the notebook-generated deduplication audit directory.
